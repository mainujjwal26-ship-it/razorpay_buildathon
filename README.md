# Razorpay Trusted Collections Agent

A Hindi voice agent for bounced personal-loan EMIs that recommends who takes the borrower next, the AI or a person, and plans the next collection cycle. Built for the Razorpay x ISB Build Challenge, Track 2: Recover and Grow with AI.

- **[AI build log](AI_BUILD_LOG.md)**: tools and models, prompts and workflow, a rejected AI output, what AI did versus what I decided, and limitations.
- **[One-page product note](note/product-note.pdf)**: problem, evidence from three lender interviews, solution, decisions, what was left out, and the success metric.
- **Agent content**: everything that governs what the agent says and when it hands over is in [`content/`](content/).
- **Demo mode** runs the real screens on sample data; **Live mode** places a real call.
