Sample data for the Performance page. These calls are synthetic: they are not real borrowers or real calls. The page labels them "Sample data" and they can be switched off. Real calls come from `call-logs/`.

The sample is 100 targeted payments of ₹5,000 each (₹5,00,000 in total). Each call carries simulated `payment` figures, `handoff` and `plannedHuman`. For the demo, a payment link that has been sent counts as paid, and the days-to-resolve numbers are placeholders so the metric reads as a real number.
